## ① 예상수익 — 회원 등급별 차등 노출 ✅ 완료

**요청**: 등급(첫구매/일반/컨시어지)별로 예상수익이 다르게 보이게, 등급 추가도 가능하게

**구현**
- **수수료율을 상품 → 회원 등급으로 이전** (상품별 수수료율 필드 완전 제거)
- 기본 3등급 자동 생성: **첫구매 20% / 일반 7% / 컨시어지 13%**
- **첫구매**(판매실적 0건) → 판매 1건부터 **일반** 자동 전환
- **컨시어지 등 그 외 등급은 어드민이 회원별로 직접 지정**
- 어드민 `등급/수수료율` 메뉴: 등급명·퍼센트·순서 편집, **등급 추가/삭제 가능**
- 상품 카드·상세의 예상수익이 **보는 사람 등급 기준**으로 표시 (비로그인은 "최대 %")
- 마이페이지에 **내 등급 + 수수료율** 표시
- 판매 수수료 계산도 등급 기준으로 변경

## ② 통장사본·신분증 접수 + 어필리에이트 약관 ✅ 완료

**요청**: 마이페이지에서 서류 접수, 가입 시 약관 동의

**구현 — 가입 1단계 (진입장벽 최소화, 주민번호 안 받음)**
- 실명 · 이메일 · 휴대폰 본인인증 · 아이디/비밀번호
- **동의 4필수 + 1선택** (전체동의 지원, 미동의 시 가입 불가)
  - 서비스 이용약관 / 개인정보 수집·이용(가입) / 파트너 운영정책·대가성 표시 서약 / 만 14세 이상 / (선택) 마케팅 수신
- **동의 이력 저장** (항목별 + 약관 버전 + 시각)

**구현 — 정산 2단계 (지급 시점에만 수집)**
- 주민등록번호 · 주소 · 은행/계좌/예금주 · **신분증 사본 · 통장 사본**
- **예금주 = 회원 실명 자동 검증** (타인 명의 차단)
- 정산용 개인정보 동의 필수

**보안**
- 주민번호 **AES-256-GCM 암호화 저장**, 화면에선 `900101-1******` 마스킹
- 서류는 **비공개 저장소(Private Blob)** — 공개 URL 자체가 없음
- 어드민만 **서버 프록시**로 열람 (`no-store`), 계좌번호도 마스킹

**약관 5종 작성** (`/terms` 공개 페이지)
- 부정 실적 조항 포함: 본인구매·동일IP 반복·매크로·허위광고·상표 무단사용 → 지급 보류/자격정지/반환청구

**정산 정책 확정**

| 항목 | 기준 |
|---|---|
| 수익 확정 | 구매확정(배송완료 +7일) |
| 집계 | 매월 1일~말일 |
| 지급일 | 익월 15일 (휴일이면 다음 영업일) |
| 최소 지급액 | 30,000원 (미달 시 이월) |
| 상한 | 없음 |
| 세금 | 3.3% 원천징수 |
