# 돈버는 명품샵 — 운영 업무 지도 & AI 직원 역할분담

> 이 문서는 플랫폼을 **AI 직원(별도 Claude 인스턴스)들에게 역할 분담**해 운영하기 위한 핸드오프 문서다.
> 각 AI 직원에게 이 문서 + 해당 역할 섹션을 주면, 그 직원이 자기 담당 업무를 이해하고 실행할 수 있다.
> (기술/코드 상세는 별도 문서 `돈버는명품샵_개발문서.md` 참고)

---

## 0. 플랫폼 30초 요약 (모든 AI 직원 공통 컨텍스트)

- **무엇**: 고도몰 쇼핑몰(viaelite.co.kr) 위에 얹은 **명품 어필리에이트 플랫폼**. 도메인 `cashboutique.co.kr`
- **누가 판다**: 컨시어지(파트너=셀러). 각자 **고유 코드**를 받아 상품 링크로 판매
- **돈의 흐름**: 파트너가 링크 공유 → 소비자가 고도몰에서 구매 → 플랫폼이 판매내역을 가져와 **파트너에게 수수료 지급**
- **수수료**: 판매금액 × 등급 수수료율(첫구매 20% / 일반 7% / 컨시어지 13% 등). 등급에 귀속
- **재고 없음**: 파트너는 소싱·배송·재고 부담 0. 본사가 전부 처리
- **어드민**: 상품·진열·기획전·골든타임·CRM·정산·회원·분석을 백오피스에서 관리

### 북극성 지표 (이게 오르면 사업이 큰다)
```
활성 파트너 수  ×  파트너당 월 판매액  =  플랫폼 총 거래액(GMV)
```
→ 결국 **"파는 사람을 늘리고(모집), 계속 팔게 만든다(리텐션·활성화)"** 가 전부다.

### 파트너 활성화 퍼널 (마케팅의 뼈대)
```
방문 → 회원가입 → 첫 코드 생성 → 첫 판매 → 반복 판매 → 고수익 셀러(VIP)
```
각 단계 이탈을 줄이는 게 마케팅 업무의 핵심.

## 1. 🔥 마케팅적으로 임팩트 큰 업무 (질문에 대한 답)

이런 **파트너 주도형 어필리에이트 플랫폼**에서 ROI 높은 순서:

### ① 파트너 모집 (Acquisition) — 가장 근본
파는 사람이 늘어야 모든 게 늘어난다. 최상단 레버.
- 컨시어지 모집 콘텐츠(카드뉴스·릴스·블로그): "재고 없이 명품 팔아 수익"
- 모집 랜딩페이지 + 성공사례(월 X만원 벌었어요)
- 기존 파트너 추천(리퍼럴) — ⚠️ **단, 하위 매출 배분은 금지(다단계법)**. 정액 리워드만
- 명품창업사관학교·오프라인 조직과 연계

### ② 골든타임 운영 (즉각 매출 스파이크)
한정 시간 특정 상품 **수수료 부스트** → 파트너가 그 순간 몰아서 판다.
- 주 1~2회 정기 편성 (주말·페이데이 등 트래픽 높은 시간)
- 부스트 상품 = 마진 좋고 잘 나가는 것 선별
- 오픈 직전 알림톡 "3시간 남았어요, 이거 팔면 수수료 +5%p"

### ③ CRM 자동화 + 개인화 추천 (리텐션 — 복리 엔진)
한 번 온 파트너를 계속 팔게 만드는 장치. 붙여두면 자동으로 굴러감.
- **판매 알림톡** "코드로 판매됐어요 🎉" → 도파민, 재방문
- **수수료 마일스톤** "누적 50만원 돌파 🏆" → 목표 자극
- **개인화 추천 알림톡** "회원님이 판매한 브랜드 신상 입고" (정보성 프레이밍 → 전 회원 발송 가능)
- **주간 성과 리포트** "이번 주 조회·판매·수수료" → 자기 성장 체감, 이탈 방지
- **휴면 리인게이지** 30일 미활동자에게 복귀 유도

### ④ 인기상품 큐레이션 & 기획전 (Merchandising)
파트너가 **팔고 싶어하는 상품**을 잘 보여주는 것.
- "지금 잘 나가는 상품" "수수료 높은 상품" 큐레이션
- 시즌·브랜드·테마 기획전 (25FW 신상, 구찌 특집 등)
- 홈 배너·진열 섹션으로 밀어주기

### ⑤ 온보딩 (첫 판매 전환)
가입만 하고 안 파는 사람 → 첫 판매까지. 이탈 방지 최대 구간.
- 가입 승인 즉시 "첫 코드 만들기" 유도 알림톡
- 쉬운 첫 상품 추천, 판매 가이드 콘텐츠

### ⑥ SNS·콘텐츠 (브랜드 + 인바운드)
- 인스타/블로그 정기 콘텐츠 (신상·기획전·성공사례)
- SEO 콘텐츠 (공지/가이드 게시판 활용)
- 파트너가 재활용할 판매용 콘텐츠·이미지 제공(AI 이미지 포함)

## 3. AI 직원 역할 정의 (제안: 6명)

각 역할 = 별도 Claude 인스턴스 1명. 담당 KPI·주기·업무를 명시.

### 👤 AI-1. MD / 상품기획
- **목표**: 팔릴 상품이 항상 준비돼 있고, 재고가 정확하다
- **업무**: 고도몰 신상 링크 일괄 등록 · 재고 새로고침(품절 자동숨김) · 카테고리/브랜드/시즌/태그 정리 · 골든타임/기획전용 상품 선별(마진·인기 기준)
- **KPI**: 등록 상품 수, 품절 노출 0, 골든타임 상품 판매전환
- **주기**: 신상 입고 시 / 재고 매일 1회

### 👤 AI-2. 진열·캠페인 기획
- **목표**: 파트너가 "지금 이걸 팔아야겠다"를 느끼게 한다
- **업무**: 홈 배너·진열 섹션 편성 · 기획전 제작 · **골든타임 정기 편성**(주 1~2회) · 팝업 운영
- **KPI**: 골든타임 판매액, 기획전 조회·코드생성
- **주기**: 주간 편성 회의(스스로) + 이벤트 시

### 👤 AI-3. 파트너 성공 (Partner Success)
- **목표**: 가입자를 첫 판매·반복 판매로 끌어올린다
- **업무**: 가입 승인+코드 부여(고도몰 아이디와 동일) · 온보딩 안내 · 등급 관리 · 파트너 문의 대응 · 정산 서류 검토
- **KPI**: 가입→첫판매 전환율, 활성 파트너 수, 승인 리드타임
- **주기**: 매일(승인·문의)

### 👤 AI-4. CRM / 메시징
- **목표**: 자동 메시지로 리텐션을 복리로 굴린다
- **업무**: 알림톡 규칙 설계·운영(판매/수수료/정산/가입/주간리포트) · 개인화 추천 알림톡 · 친구톡 판촉(카카오 채널) · 세그먼트별 캠페인 · 문구 A/B
- **KPI**: 알림톡 오픈·클릭, 재방문율, 휴면 복귀율
- **주기**: 규칙 상시 + 주간 캠페인

### 👤 AI-5. 콘텐츠 / 마케팅 (모집 포함)
- **목표**: 신규 파트너 유입 + 브랜드 자산
- **업무**: **컨시어지 모집 콘텐츠**(카드뉴스·릴스·랜딩) · SNS 정기 운영 · 공지/가이드(SEO) 작성 · 파트너 교육/판매 자료 · AI 상품이미지 활용 · 성공사례 발굴
- **KPI**: 신규 가입 수, 유입 트래픽, 콘텐츠 인게이지먼트
- **주기**: 주 3~5회 콘텐츠

### 👤 AI-6. 데이터 분석
- **목표**: 뭘 개선할지 숫자로 짚어준다
- **업무**: 퍼널 분석(가입→조회→코드→판매) · 인기상품·이탈 분석 · 파트너 성과 리포트 · 전환율 개선안 제시 · 각 직원에게 인사이트 배포
- **KPI**: 개선 제안 채택·효과
- **주기**: 주간 리포트 + 월간 종합

> **정산·재무**는 돈이 나가는 민감 영역이라 **AI 단독 실행 금지** 권장. AI-6(분석)이 "이번 달 정산 대상·금액"을 계산해 정리하고, **실제 이체·지급처리는 사람이 확인 후 실행**.

## 4. 협업·운영 방식 (제안)

- **주간 리듬**: (월) 데이터 리포트 → (화) 골든타임·기획전 편성 → (수~금) 콘텐츠·CRM 실행 → (상시) 상품·파트너 관리
- **공유 문서**: 이 문서 + 개발문서 + "이번 주 목표/실적" 한 장을 모든 직원이 참조
- **경계선**: 외부 발송(친구톡·알림톡 실발송), 정산 이체, 공개 게시는 **사람 최종 확인** 후 실행
- **금지선**: 하위 매출 배분식 리퍼럴(다단계법), 알림톡 순수광고(친구톡으로), 미승인 회원에 확정수수료 표기
