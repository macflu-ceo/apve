## 1. 플랫폼 개요

### 1.1 무엇을 하는 서비스인가
**돈버는 명품샵**은 기존 고도몰 쇼핑몰(`viaelite.co.kr`) 위에 얹은 **어필리에이트(제휴 판매) 플랫폼**이다.

- **컨시어지(파트너)** 는 플랫폼에서 상품을 골라 자신의 **고유 코드가 붙은 판매 링크**를 만든다.
  - 링크 형태: `https://viaelite.co.kr/goods/goods_view.php?goodsNo=<상품번호>&code=<파트너코드>`
- 그 링크로 소비자가 구매하면, 고도몰이 `code`(영업사원 코드) 기준으로 주문을 기록한다.
- 플랫폼은 그 판매내역을 가져와 **파트너에게 수수료를 지급**한다.
- 재고 없이, 코드 하나로 명품을 판매하고 수익을 올리는 구조.

### 1.2 핵심 개념
| 용어 | 의미 |
|---|---|
| 컨시어지 / 파트너 | 상품을 파는 회원(셀러). 고유 코드를 부여받음 |
| 코드 | 파트너 식별자 = **고도몰 영업사원 아이디**와 동일 (예: `cd001ws`) |
| 등급 | 파트너별 수수료율 구간 (첫구매 20% / 일반 7% / 컨시어지 13% 등) |
| 수수료(수익) | 판매금액 × 등급 수수료율 |
| 골든타임 | 한정 시간 동안 특정 상품의 수수료율이 올라가는 이벤트 |

## 2. 기술 스택 & 아키텍처

| 영역 | 기술 |
|---|---|
| 프레임워크 | Next.js 14 (App Router) + TypeScript + React 18 |
| 스타일 | Tailwind CSS (Queenit 스타일 커스텀 팔레트) |
| DB | PostgreSQL (Neon, Vercel Storage) + Prisma ORM |
| 파일 저장 | Vercel Blob — 공개 스토어(상품/배너 이미지) + 비공개 스토어(신분증/통장) |
| 인증 | 자체 구현 (scrypt 비밀번호 해시 + HMAC 서명 httpOnly 쿠키) |
| 민감정보 | 주민등록번호 AES-256-GCM 암호화 |
| AI 이미지 | Google Gemini (`gemini-2.5-flash-image`) |
| 트래픽 분석 | Vercel Analytics |
| 배포 | GitHub → Vercel 자동 배포 |

### 2.1 화면 구조 (라우트 그룹)
- **`(shop)`** — 소비자/파트너용 쇼핑몰 (독립 헤더·푸터)
- **`/admin`** — 백오피스 (별도 레이아웃, 로그인 게이팅)
- 루트 레이아웃은 껍데기만 담당

### 2.2 고도몰 연동 아키텍처
플랫폼(Vercel)과 고도몰(별도 서버)은 **커스텀 API로 통신**한다. 고도몰 `module/Controller/Api/` 에 PHP 컨트롤러를 올려 `api.viaelite.co.kr` 로 노출.

```
[플랫폼/Vercel]  ──(HTTPS + X-API-KEY)──▶  [고도몰 api.viaelite.co.kr]
   판매 동기화                                  /concierge/sales   (판매내역)
   재고 갱신                                    /concierge/stock   (사이즈별 재고)
```

## 3. 소비자(쇼핑몰) 기능

### 3.1 상품 탐색
- **홈** — 히어로 배너(3초 자동 전환, 좌우 스와이프), 카테고리 칩, 진열 섹션(어드민 커스텀)
- **필터 상품탐색** (`/category`) — 검색 대신 필터 방식
  - 카테고리 · 브랜드 · 시즌(26SS/25FW) · 가격대 필터
  - 정렬: 최신등록 · 수수료↑↓ · 공급가↑↓ · 정가↑↓ · 할인율 · 최신시즌
  - 필터는 URL에 저장되어 공유·뒤로가기 가능
- **상품 상세** (`/goods/[goodsNo]`)
  - 브랜드/원산지/**사이즈별 재고**(품절 취소선) + 사이즈표 팝업(HTML 6탭)
  - 예상 수익(등급별) 표시
  - **내 코드 만들기** 버튼 → 파트너 링크 발급
  - **AI 이미지 만들기** (회원 전용)
- **기획전** (`/exhibition/[id]`) — 어드민이 만든 독립 상품 큐레이션 페이지

### 3.2 골든타임 (한정 수수료 부스트)
- 맨 위 **배너** — 진행중(커스텀 색상)/오픈예정(다크), 실시간 카운트다운
- 진행 중일 때 해당 상품은 **모든 목록에서 수수료 영역이 빨강 상승화살표로 강조**
- `/timesale` 페이지 — 진행중이면 부스트 상품, 예정이면 잠금 티저

### 3.3 회원(파트너)
- **2단계 가입**
  1. 1단계: 아이디/비번/이름/이메일/휴대폰 + 본인인증 + 약관 동의(4필수 1선택)
  2. 2단계: 정산정보(주민번호·계좌·신분증·통장) — 최소 지급액 도달 시
- **내정보(마이페이지)** — 판매 건수/매출/예상수익/확정수익, 판매내역, 발급 링크, 정산정보 등록
- 멤버십 업그레이드(컨시어지 신청) — 이미 상위 등급이면 자동 숨김

### 3.4 기타
- **공지 / 가이드** 게시판 (`/board`) — 이미지·동영상 임베드
- **팝업** — 가운데 모달, 2개 이상 캐러셀, "오늘 하루 보지 않기", 노출 기간 설정
- **약관/정책** (`/terms`) — 이용약관·개인정보처리방침·취소환불정책

## 5. 고도몰 연동 상세

### 5.1 판매내역 API (`/concierge/sales`)
- 고도몰 관리자 [영업사원 통계]와 동일한 조인·제외조건을 사용
- 파일: `module/Controller/Api/Concierge/SalesController.php`
- 인증: `X-API-KEY` 헤더 또는 `key` 파라미터
- 파라미터: `from`, `to`, `code`(선택), `scope`(valid/all), `limit`
- 응답: 주문번호·코드·주문일·**구매확정일**·주문상태·정산상태·상품·옵션·금액
- 개인정보(고객 주소)·매입원가는 응답에서 **제외**

**동기화 로직** (`lib/godomall/sales.ts`)
- `syncKey(orderNo|goodsNo|optionName)` 로 중복 없이 upsert
- 미결제 제외, 취소/반품은 `canceled` 로 반영
- 수수료 = 판매금액 × (등급% + 골든타임 부스트)
- code = 파트너 코드 매칭 (없으면 "미매칭")

### 5.2 재고 API (`/concierge/stock`)
- 파일: `module/Controller/Api/Concierge/StockController.php`
- `es_goodsOption` 테이블 직접 조회 → 색상/사이즈별 재고
- 콤마로 여러 상품 일괄 조회(최대 100개), 판매중 옵션만
- 상품 등록·재고 새로고침 시 사용 (HTML 스크래핑보다 가볍고 정확)

### 5.3 인증키 관리
- API 키는 **Vercel 환경변수**(`GODO_SALES_API_KEY`)와 PHP 파일에만 존재
- 공개 저장소(GitHub)에는 플레이스홀더만 커밋

## 8. 운영 가이드

### 8.1 배포
1. 코드 수정 → GitHub Desktop **Push** → Vercel 자동 배포
2. DB 스키마 변경 시 배포 과정에서 `prisma db push`로 자동 반영 (데이터 유지)
3. ⚠️ **Redeploy 시 항상 최신 배포(Production 배지)에서** — 옛 배포 재배포 금지

### 8.2 필수 환경변수 (Vercel)
| 변수 | 용도 |
|---|---|
| `DATABASE_URL` | Neon PostgreSQL |
| `BLOB_READ_WRITE_TOKEN` | 이미지 저장 (공개) |

| `GOOGLE_SITE_VERIFICATION` / `NAVER_SITE_VERIFICATION` | SEO 소유확인 |

### 8.3 고도몰 API 파일 배포
1. FileZilla로 `data/module/Controller/Api/Concierge/` 에 PHP 업로드
2. 개발소스관리 → 소스검증 → 운영소스에 적용 (또는 FTP 직접 반영)

### 8.4 파트너 승인 절차
1. 고도몰에서 영업사원 아이디 발급 + 영업사원 플래그(`salesAgentFl='y'`)
2. 어드민 회원관리에서 승인 시 **코드 = 그 아이디**로 입력 (완전 동일해야 매칭)

### 8.5 월 정산 절차
1. 판매내역 → 고도몰에서 가져오기(해당 월)
2. 정산 메뉴 → 구매확정·미지급 건 파트너별 확인
3. 실지급액(원천징수 3.3% 차감) 계좌이체 → "지급 완료 처리"
