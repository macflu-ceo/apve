## ✅ 확정된 결정
- **기술 스택**: Next.js 풀스택 (프론트 + 어드민 + API Routes + DB 한 프로젝트)
- **판매 추적**: 고도몰(프로)이 유입 파라미터를 주문에 기록함 → 우리는 그 데이터를 **가져오기(pull)만** 함
- **AI 착용샷**: 이번 MVP 범위에 **포함** (사용 서비스명 확인 필요)
- **쇼핑몰**: 고도몰 **프로** / 도메인 `viaelite.co.kr`

## 🔗 고도몰 URL 구조 (확인 완료)
```
https://viaelite.co.kr/goods/goods_view.php?goodsNo=1000466837&code=ic001ws
                                            └ goodsNo=상품번호 ┘ └ code=파트너코드 ┘
  (mtn=1^|^PRODUCT^|^n 는 메뉴경로 추적용, 판매링크엔 불필요)
```
- **상품 식별자**: `goodsNo`
- **파트너 고유 파라미터**: `code` ← "내 코드 만들기" = `기본URL + &code=<파트너코드>`
- 판매 링크 최소형: `https://viaelite.co.kr/goods/goods_view.php?goodsNo=<번호>&code=<코드>`

## 🕷️ 상품 스크래핑 (검증 완료)
상품 URL 페이지에서 아래 필드 추출 가능 (WebFetch로 실측):
- 상품명, 정가, 판매가, 브랜드, 사이즈/옵션, 재고, 소재, 배송정보
- 이미지 패턴: `jprimo-partners-system-bucket/products/jprimo-product-<id>/N.jpg` (여러 장)
→ 어드민에서 URL 붙여넣기 → 자동 수집 → 등록 방식으로 구현

## 1. 한 줄 정의

기존 **고도몰 쇼핑몰**의 상품을, 파트너(컨시어지)가 **자기 고유 파라미터를 붙인 링크**로
쉽게 발급·판매하고, 그 성과를 추적·정산하는 **어필리에이트 플랫폼**.

---

## 2. 비즈니스 맥락

- 모회사: 제이프리모인터내셔널 / 브랜드: 비아엘리떼 (viaelite.kr)
- 판매 조직: 럭셔리 컨시어지 = 이 플랫폼의 **파트너**
- 상품 원천: 기존 고도몰 쇼핑몰(이미 개발/운영 중) → 이 플랫폼은 그 기능을 **활용**
- 톤: 품위 있고 권위 있는 럭셔리. 과장·MLM식 표현 금지.

---

## 3. 핵심 개념 — 어필리에이트 추적

1. 파트너 1명당 **고유 파라미터** 부여 (어드민에서 회원등록 시 설정)
2. 파트너가 상품 상세에서 **"내 코드 만들기"** 클릭
   → `상품URL + ?파라미터=파트너코드` 형태의 링크 즉시 발급
3. 그 링크로 유입되어 발생한 판매 = 해당 파트너 성과로 집계
4. 파트너는 **내정보**에서 발급한 코드/판매내역/수익 확인

> ⚠️ 미확정: 판매 성과를 "어디서" 추적하는가?
> - (A) 고도몰이 URL 파라미터를 주문에 기록 → 그 데이터를 가져온다
> - (B) 우리가 별도로 클릭/전환을 추적한다
> 이 결정이 전체 아키텍처를 좌우함. → 5번 오픈 이슈 참고.

## 4. 기능 명세 (MVP 범위)

### 4.1 프론트 (파트너용, 쇼핑몰 형태)
- 메뉴: **전체상품보기 · 카테고리보기 · 내정보 · 가이드 · 정식 컨시어지**
- 상품 리스트 / 카테고리 필터 / 상품 상세
- 상품 상세: 이미지, 상품명, 가격, 사이즈, 재고, 상세페이지, **예상 수익**
- **"내 코드 만들기"** 버튼 → 내 파라미터 붙은 판매 링크 발급 + 복사
- **내정보**: 내 파라미터, 발급한 코드 목록, 판매내역, 수익 합계

### 4.2 어드민
- **상품 등록**: 고도몰 상품 URL 입력 → 상품명/재고/이미지/사이즈/상세페이지 자동 수집 후 등록
- **회원(파트너) 등록**: 파트너 생성 + **고유 파라미터 지정**
- 상품별 파트너 예상 수익(수수료율) 설정
- 판매내역 수집/조회

### 4.3 AI 기능
- **AI 착용샷 생성**: 상품 이미지가 한정적이므로, 착용 이미지를 AI로 생성
  - (미정) 사용 서비스 / MVP 포함 여부
